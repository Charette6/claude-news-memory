## AI & autonomous systems

### One operator ran an open-source AI pentest agent plus Claude Code against several South Korean banks and left the session logs exposed
Slug: `artex-claude-code-korean-bank-intrusions` | event, high confidence | origin: feed (The Register; CrowdStrike blog as primary, dated 7 October)

CrowdStrike found open directories on attacker infrastructure (Hong Kong primary server plus a separate ARTEX host) containing Claude Code session histories, ARTEX configuration and Claude memory files. The actor ran ARTEX, a recently released Chinese open-source agentic pentest tool, on DeepSeek v4.1-flash via an API reseller, and used GLM-5.3 and Grok 4.6 in further Claude Code sessions with a Chinese-language pentest prompt. Targets: a broker-facing loan progress inquiry service at one bank and an employee mobile work-support system at another; data exfiltrated. The actor asked the model where Korean breach data is sold and had it write a résumé highlighting the campaign. CrowdStrike assesses a likely Chinese-speaking, financially motivated actor with moderate confidence; it provides IOCs (nine proxy IPs, one actor IP). Register adds per-bank victim counts reported in Korea (Shinhan ~25,000; KB Kookmin 119; Hana 89) and a 19 October parliamentary audit.

Orchestrates Gemini and Claude models. Financial customers named: BNP Paribas, Bradesco, DBS, Commerzbank, Lloyds, Starling, Airwallex, PayPal, Banco BV, CME Group, Deutsche Bank, Zip, Berenberg. Gemini for Financial Services is in preview. Vendor claims, not verified.
