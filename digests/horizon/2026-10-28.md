### Claude Code adds a switch that removes the last approval prompt for file deletion
- Slug: `claude-code-rm-approval-bypass-flag`
- Summary: Claude Code v2.1.311 supports `CLAUDE_CODE_EVEN_MORE_DANGEROUSLY_SKIP_PERMISSIONS=1`. It lets the agent run rm and rmdir without approval and lifts the block on `rm -rf ~` that remains under the existing skip-permissions flag. A staff member announced it on social media and it is not in the changelog. Managed settings may still impose limits.
