## AI & autonomous systems

### Coding agents reach exploit primitives on over half of Linux kernel CVEs in a new benchmark

Slug: `kex-bench-agent-kernel-exploits`

Preprint "Evaluating Coding Agents on Kernel Exploit Generation" introduces KEX-bench: 45 task instances spanning 40 Linux and Windows CVEs, targeting kernel address leak, instruction-pointer control, heap read, heap write and arbitrary address write. State-of-the-art coding agents paired with frontier and open-weight models were run under fixed tool-call budgets. Without reference proof-of-concept code, the best result was 56% on Linux (14/25) and 5% on Windows (1/20). With a reference PoC, success rose to 68.9% (31/45). The authors highlight a gap where agents reach kernel crashes but fail to shape kernel state into exploit primitives. Seven authors; submitted 2026-09-22.

Why it matters: the time from a published kernel CVE to a usable exploit primitive is increasingly bounded by agent runtime rather than attacker skill, especially on Linux. Argues for tighter kernel patch SLAs on internet-facing Linux and container hosts.

Confidence: lab result, moderate (preprint, benchmark conditions).

Sources:
- https://arxiv.org/abs/2609.25591

### Black-box hijacking of MCP agents through poisoned tool metadata and outputs

Slug: `a2m-mcp-agent-hijacking`

Preprint "A2M: Trace-Optimized Agent Hijacking in the MCP Ecosystem" describes a two-stage black-box attack on Model Context Protocol agents. Stage one optimises a third-party tool's metadata to raise the probability the agent invokes it; stage two manipulates the tool's execution-trace outputs to steer the agent toward attacker objectives. On LiveMCPBench, optimised on GLM-4.6, it achieved a 93.6% malicious tool invocation rate and a 74.4% mean success rate across three categories (information exfiltration, environment integrity compromise, reasoning derailment). Transferred to other models without re-optimisation: 63.6% invocation, 24.5% success. The paper also demonstrates a "cognitive denial of service" that raised token cost to 32.4x baseline. Accepted at AACL-IJCNLP 2026; code public. Submitted 2026-09-22.

Why it matters: any agent deployment that can register third-party MCP tool servers inherits a semantic supply chain. Tool metadata and outputs need the same gating and review as browser extensions or third-party packages.

Confidence: lab result, moderate (benchmark, transfer rates lower).

Sources:
- https://arxiv.org/abs/2609.26761
