## P1 — Added to CISA KEV in the last 24 hours

### CVE-2026-109618 — PHP (memory corruption, "php2shell")
- CVSS 9.8 (NVD v3.1) · EPSS 0.99981 · KEV added 2026-10-26, due 2026-10-29 · ransomware use: Unknown
- Out-of-memory handling via longjmp() leaves request memory uninitialized; subsequent cleanup reads/branches on it → unauthenticated RCE. Full RCE demonstrated on Apache mod_php with default limits; PHP-FPM, FrankenPHP, LSAPI assessed susceptible by source analysis.
- Fixed in: PHP 8.5.12, 8.4.27, 8.3.36, 8.2.35. PHP ≤8.1 unsupported — upgrade or take offline.
- Mitigations (incomplete): memory_limit=-1 enforced across all workers; restrict multipart input at the frontend; do NOT use RLIMIT_AS/RLIMIT_DATA (failed mmap() still triggers the path).
- Sources: https://github.com/php/php-src/security/advisories/GHSA-w8hw-w9fx-j79w · https://www.cisa.gov/news-events/alerts/2026/10/21/critical-vulnerabilities-php-require-immediate-patching · https://www.wiz.io/blog/php2shell-php-rce · https://nvd.nist.gov/vuln/detail/CVE-2026-109618
- Status: previously tracked; CHANGED (added to KEV 2026-10-26).
