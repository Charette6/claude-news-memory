# Security News Digest — 2026-11-01

Window: 24 hours to 2026-11-01 08:03 (Jordan time) / 05:03 UTC.

## Stories

### Chainalysis confirms breach of internal tools; customer identity data exposed
Blockchain-analytics firm Chainalysis said an external actor used "offensive agentic techniques" (AI-driven attack tooling) to gain unauthorized access to its internal systems and tools in October 2026, exposing customer user IDs, full names, email addresses and organisation role labels. The company says investigation content, authentication credentials and session tokens were not accessed, and has given no count of affected organisations.
- https://thehackernews.com/2026/10/chainalysis-confirms-intrusion-into.html
- https://www.bleepingcomputer.com/news/security/chainalysis-discloses-data-breach-from-offensive-agentic-techniques/

### Cloud platform Northflank breached; customers' stored API keys abused (single source)
Northflank disclosed a security incident on 30 October after customers reported unauthorized use of AI API keys stored on the platform, and told customers to assume all environment variables were decrypted and to rotate every stored secret. Wiz, assisting with incident response, counts at least nine incidents at AI developer platforms in October; in two investigated cases, stolen enterprise credentials generated roughly $100,000 of fraudulent API usage via about 2.5 million Amazon Bedrock API calls.
- https://www.bleepingcomputer.com/news/security/northflank-security-breach-leads-to-abuse-of-customers-ai-api-keys/

### VOLTA infostealer uses an AI model to rank victims by monetizable value (single source)
Cisco Talos documented VOLTA ("VOLTA-AUTODOXER"), a build-to-order Windows infostealer that harvests browser passwords, payment cards, crypto wallet seed phrases, OAuth tokens, SSH and cloud keys, then sends a victim dossier to a commercial LLM via OpenRouter, which returns a ranked assessment of the victim's monetizable assets and security posture. Talos reports no victim counts; all observed infrastructure is third-party services.
- https://blog.talosintelligence.com/appraisal-by-ai-model-driven-victim-prioritization-in-the-volta-infostealer/

### Malicious shared ChatGPT link could run attacker code and read private chats (fixed)
Researchers at Parameter showed a shared ChatGPT conversation link could execute attacker-controlled code in the viewer's session with full access to their account, including reading private conversations. OpenAI rated it P1 and fixed it by 26 October; no user action is needed and no real-world exploitation was reported.
- https://thehackernews.com/2026/10/a-shared-chatgpt-link-could-run.html

### Three Ivanti Connect Secure flaws chained for unauthenticated root access (vulnerability — see Vulnerability Brief)
Volexity documented an actor (UTA0576) chaining CVE-2026-104935, CVE-2026-111357 and CVE-2026-118527 for unauthenticated root-level code execution on Ivanti Connect Secure VPN appliances, extracting credentials and Active Directory metadata; CISA added the flaws to its Known Exploited Vulnerabilities catalog and Ivanti has released patches.
- https://thehackernews.com/2026/10/attackers-chain-three-ivanti-connect.html
- https://securityaffairs.com/202175/security/u-s-cisa-adds-ivanti-connect-secure-flaws-to-its-known-exploited-vulnerabilities-catalog.html

### Critical Drupal Commerce Core flaw exploited against online stores (vulnerability — see Vulnerability Brief)
Drupal maintainers confirmed active exploitation of CVE-2026-118539, a critical missing-authorization flaw in Commerce Core that allows access bypass on store routes and entity fields; fixed releases are available (8.x-2.41 and 3.3.13 branches).
- https://securityaffairs.com/202162/security/attackers-exploit-critical-drupal-commerce-core-vulnerability-cve-2026-118539.html
