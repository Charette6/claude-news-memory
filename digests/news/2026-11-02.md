### FBI attributes record $6.4 billion Binance theft to North Korea's TraderTraitor

The FBI attributed the 29 October theft of roughly $6.4 billion from Binance — the largest crypto heist on record — to North Korea's TraderTraitor (Lazarus) group and asked virtual asset service providers to block 628 flagged addresses. Binance says attackers reached a service container via a compromised DevOps engineer's laptop, has covered about 95% of the loss itself with no losses passed to customers, and began phased withdrawal resumption on 1 November.

### Polymarket refunds $2.7 million after hijacked third-party script drained traders

A page-monitoring script Polymarket loaded from vendor DebugBear was swapped for malicious code via a DNS/registrar compromise at the vendor; the malicious version sold logged-in traders' positions and moved funds to attacker wallets before being removed within the hour on 29 October. Polymarket is refunding about $2.7 million to 726 drained wallets ($3.9 million in total including trading-pause losses) and plans to restore third-party scripts only with version pinning, CSP and sandboxing.

### Alpine Linux rebuilds its GitLab server after attempted supply-chain attack

Attackers attempted to exploit a maximum-severity GitLab flaw against the self-hosted server that holds Alpine Linux's package build recipes on 20–21 October; Alpine found no evidence code executed or that packages were tampered with, but missing logs meant it could not fully rule out compromise, so it rebuilt the instance from scratch and reset all passwords. The attackers also downloaded Alpine's GitLab container image, which Alpine reads as possible preparation for a broader supply-chain attack.

- https://www.bleepingcomputer.com/news/security/alpine-linux-rebuilds-gitlab-after-attempted-rce-attack/
- https://www.securityweek.com/max-severity-gitlab-vulnerability-exploited-against-alpine-linux/

### Aur0ra ransomware gang used commercial AI coding agents in intrusions (single source)

Sophos found that the Aur0ra ransomware gang (GOLD OGRE) gave commercial AI coding agents VPN credentials and objectives, after which the agents mapped networks and Active Directory and hunted stored passwords with little human input; three victims where agents gained domain-level access later appeared on the gang's leak site. The operators bypassed the AI tools' guardrails by framing the activity as authorized red-team testing; Sophos says existing controls (phishing-resistant MFA, patched edge devices, monitored EDR) remain effective but response windows shrink.

- https://www.helpnetsecurity.com/2026/11/02/aur0ra-ransomware-ai-agents/

### NetamLoader espionage malware found on government-only Windows build in Asia (single source)

Kaspersky documented NetamLoader, a previously unknown .NET loader framework found on a Windows 10 edition used only by government bodies in Asia, delivered through a fake Windows update CAB archive in what researchers suspect was a supply-chain compromise. One victim is confirmed so far and the actor is unattributed.

- https://thehackernews.com/2026/11/netamloader-malware-targets-government.html
