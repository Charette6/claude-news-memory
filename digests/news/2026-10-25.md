## Stories

### Capcom breach exposes 11.8 million customer email addresses
`capcom-id-breach`

Capcom confirmed unauthorised access to its CAPCOM ID membership service, discovered 19 October 2026, exposing 11,774,247 email addresses together with account metadata including creation dates, login counts and last-login IP addresses; in 43 cases date of birth, gender, country/region and nickname were also exposed. Passwords were illegally changed on 196 accounts, which Capcom reset; the company warns of phishing impersonating Capcom or its partners.

- https://securityaffairs.com/201626/data-breach/capcom-data-breach-exposes-11-7-million-email-addresses.html
- https://www.securityweek.com/11-million-impacted-by-capcom-data-breach/

### Poisoned release of LiteLLM AI gateway stole credentials from installing systems
`litellm-supply-chain-attack`

An attacker used a LiteLLM master key committed to a public GitHub repository in May 2026 — never revoked — to access the project's platform, harvest maintainer tokens, override branch protection and publish a malicious LiteLLM 1.107.0 to PyPI, Docker Hub and GHCR on 21 October. The implant executes whenever Python starts, even without importing LiteLLM, and includes a credential stealer plus a Unix backdoor that fetches attacker code hourly; Upwind reported the attack, with Socket and Microsoft contributing analysis, and Microsoft notes that removing only the package files leaves startup components behind.

- https://thehackernews.com/2026/10/leaked-litellm-master-key-let-attackers.html
- https://www.securityweek.com/litellm-compromised-in-fresh-supply-chain-attack/

### APT41 bootkit defeats Secure Boot on fully patched Windows machines
`blackx-uefi-bootkit`

Kaspersky attributes the BlackX UEFI bootkit, deployed in an early-2026 espionage campaign against diplomatic agencies in Tajikistan, Uzbekistan and Turkmenistan, to APT41 with medium confidence. All victims ran fully patched Windows: the bootkit exploits Baton Drop (CVE-2022-21894) and succeeded because the additional Secure Boot certificate revocations that the patch requires administrators to activate manually had not been applied. (Single-sourced.)

- https://www.bleepingcomputer.com/news/security/blackx-uefi-bootkit-exploits-baton-drop-flaw-to-bypass-secure-boot/

### Symantec traps autonomous AI attack agent that hijacks exposed model endpoints
`skynet-autonomous-agent`

Symantec's Threat Hunter Team captured, via an AI honeypot, an attacker-built autonomous agent that scans the internet for endpoints accepting OpenAI-style requests without authentication, then uses the hijacked model — at the endpoint owner's expense — to run attacks with 74 offensive tool definitions covering credential theft, database theft, remote code execution and cryptomining, permitted up to 100,000 steps without human approval. Symantec says it has no evidence of real-world victim use, though records show the agent working against a live target; no attribution has been made. (Single-sourced.)

- https://www.theregister.com/security/2026/10/24/autonomous-attack-agent-in-skynet-mode-hijacks-other-models-to-carry-out-its-evil-deeds/5305215
