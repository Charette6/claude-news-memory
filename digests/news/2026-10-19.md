## Stories

### ConnectWise suspends cloud services after its credentials were used to break into customers' Microsoft 365 tenants
`connectwise-cloud-backup-compromise`

Attackers obtained ConnectWise application credentials and used them to sign in to customer Microsoft 365 tenants as trusted apps; security firm Huntress found sign-in attempts against almost 1,000 tenants, about 300 of them successful, and in one case the attacker granted an app Global Administrator rights. ConnectWise disabled seven application identities and suspended its Cloud Backup, SaaS Security and Cloud Management services while it investigates, saying existing backup archives show no evidence of compromise.

### SiteGuard WAF flaw actively exploited for root-level command execution
`siteguard-waf-exploited` — single-sourced

SiteGuard Server Edition, a Japanese web application firewall, has an OS command-injection flaw (CVE-2026-106931) in its statistics feature that the vendor and Japan's CERT confirm is being exploited in the wild for root/SYSTEM command execution; patches are available. Covered as a one-liner here since CVE detail belongs to the Vulnerability Brief.

- https://www.bleepingcomputer.com/news/security/hackers-exploit-siteguard-waf-flaw-to-run-commands-as-system-root/

### Critical Linux KVM guest-to-host escape disclosed
`linux-kvm-guest-escape` — single-sourced

A critical (9.3) Linux KVM vulnerability allows a guest VM to escape to the host via malformed IPv4 packets; an upstream kernel fix is rolling out to distributions and no in-the-wild exploitation has been reported. Covered as a one-liner here since CVE detail belongs to the Vulnerability Brief.

- https://www.theregister.com/virtualization/2026/10/19/linux-kvm-guest-host-escape-rated-critical-may-represent-a-new-way-to-attack-penguin-powered-networking/5303744

### Semperis report: ransomware intimidation extends to employees' families
`semperis-ransomware-intimidation-report` — single-sourced

A Semperis survey of 1,200 organisations that suffered a successful ransomware attack found attackers threatened employees' family members or friends at 37% of them, with 23% reporting swatting incidents; 59% of victim organisations said they paid a ransom. The report recommends incident response plans explicitly cover threats against people outside the workplace.

- https://www.helpnetsecurity.com/2026/10/19/semperis-ransomware-employee-safety-report/
